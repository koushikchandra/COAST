a directly matched intervention. For transparency, this appendix reports every evaluated architecture,
including the neutral TRIPLEX result and the negative BLEEP result. No model was removed from the

\paragraph{Paired tests.}
Wilcoxon tests on paired fold--seed values for the best LOOO variant give $p<10^{-4}$ for ST-Net and
DeepSpaCE, $p=0.0002$ for HisToGene, $p=0.074$ for Hist2ST, $p=0.032$ for the MLP probe, and
$p=0.390$ for TRIPLEX. BLEEP's global intervention decreases performance ($p=0.016$). These
preliminary values must be confirmed using validation-selected checkpoints before submission.

\paragraph{Recent-baseline execution status.}
We additionally integrated the official Gene-DML~\cite{genedml} and FEAST~\cite{feast} code releases.
Because COAST fixes UNI embeddings and fold-specific 50-gene panels, the reported Gene-DML-style row
retains its spot, neighborhood, and global streams with transformer fusion and auxiliary stream-wise
regression, but does not claim an end-to-end reproduction of the original system. FEAST results are
not reported: dense attention exceeded GPU memory for several large slides, and other runs produced
undefined validation correlations. Omitting those numbers avoids converting an engineering failure
into an apparent scientific comparison. Memory-safe FEAST reruns remain required for the final version.
